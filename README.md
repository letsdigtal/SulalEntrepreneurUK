# Sulal Entrepreneur UK — Black & Gold Website

A 16-page static HTML/CSS/JavaScript website for the Pakistan-based Sulal Entrepreneur UK business brand.

## Website

https://letsdigtal.github.io/SulalEntrepreneurUK/

GitHub Pages publishes from `main` at repository root. Check the repository's Pages build status to confirm each deployment. No separate Actions deployment workflow is needed for this branch configuration.

## Included

- Supplied gold logo, black backgrounds, gold accents, and clear mobile navigation.
- Five dedicated service pages plus About, Vision, Mission, Values, Approach, FAQ, Contact, Privacy and Terms.
- Professionally AI-edited portrait based on the supplied photo, with disclosure on the site.
- Hero service typing, optional click sounds with a mute control, scroll reveals and hover effects.
- Deep-black and softer-black appearance choices.

## Business setup still needed

Set the genuine business WhatsApp number in `assets/site-config.js` (international digits only). It is empty by default; the floating control shows a setup notice rather than an invented chat.

The static contact form is demonstration-only and does not send or store enquiries. GitHub Pages does not execute the separate WordPress/PHP mail handler. Finalize real contact information and legal text before relying on the website for live enquiries.

Service photographs are illustrative, not current stock, owned properties, or completed projects. Trust symbols represent stated commitments, not independent certifications. Forex education does not guarantee profits.

## Security

Never commit passwords, personal access tokens, or private keys. Revoke any credential that was exposed in chat or code.
